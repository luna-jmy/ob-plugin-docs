设置入口：Obsidian 设置 → 第三方插件 → **Project Master**。共七个页签。

## 全局参数

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 扫描目录 | `100 Projects` | 在哪些目录里找项目笔记，可填多个 |
| 排除目录 | `templates` | 从扫描中剔除的目录 |
| 快速项目标记 | `快速项目` | 路径中该目录段的分组特殊规则，见[字段参考](fields/#快速项目标记) |
| 中文状态别名兼容 | 开 | 状态字段里「执行中」等中文值与英文值等价识别 |
| 日期兜底策略 | 按天数推导（7 天） | 起止日期缺失时的推导规则；也可选「不上图并提示」 |
| 新建项目模板 | 空 | 新建项目时套用的模板笔记；留空不用模板 |
| 资料目录名 | `资料` | 新建项目时配套资料子文件夹的名字 |

## 字段映射

一张「信息 ↔ frontmatter 字段名」的对照表，默认值即[笔记字段参考](fields/#字段一览)里的字段名。换模板只需改这一处，代码字段名与你无关。

## 枚举与展示

- **状态**：七个默认状态的顺序、中文别名、emoji；
- **优先级**：1–5 对应的 emoji（默认 1🔴 … 5⚪）；
- **甘特条颜色**：执行中（蓝）/ 已完成（绿）/ 重要（红，优先级 1、2）/ 其他状态（灰）四类配色。

## 视图偏好

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 默认分组 | 文件夹 | 打开看板时的分组维度 |
| 默认排序 | 截止日期升序 | 列表排序规则 |
| 默认缩放 | 月 | 甘特图时间层级 |
| 默认年份筛选 | 当前年份 | 打开时的年份档 |
| 每组附带笔记数 | 5 | 分组下方附带的相关笔记条数上限 |
| 甘特条时长数字 | 关 | 是否在甘特条上显示天数 |
| 卡片文字缩放 | 100% | 面板卡片字号缩放 |
| 侧栏宽度 | 未设置 | 拖拽侧栏后自动记住 |

## Mermaid 导出

标题（默认「项目进度甘特图」）、今天标记线（开）、排除周末（关）、排除 / 仅包含日期、无分组信息时的落名（默认「默认项目」）、写入标记（`%% gantt-builder:start/end %%`）。

## 法定节假日排期

按年份维护节假日日期表，供 Mermaid 导出排期时排除。按年独立存放，逐年添加即可。

## 界面语言

跟随 Obsidian / 中文 / English。
