## 识别规则

插件只扫描设置中指定的**扫描目录**（默认 `100 Projects`，可填多个；`excludedFolders` 默认排除 `templates`）。目录内的笔记满足任一条即被识别为项目：

- frontmatter 有 `type: project`，或
- `tags` 里包含 `project`。

最小可用示例：

```yaml
---
type: project
status: active          # 中英文都认：执行中 / active
start_date: 2026-01-01
due_date: 2026-03-31
---
```

## 字段一览

下表是**默认字段名**；每一个都能在「设置 → 字段映射」里改成你自己的写法（换模板只改这一处）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `status` | 枚举 | 项目状态，见下表；中英文值都识别 |
| `start_date` | 日期 | 开始日期（YYYY-MM-DD） |
| `due_date` | 日期 | 截止日期 |
| `end_date` | 日期 | 截止日期的备用字段：`due_date` 缺失时读它 |
| `completion_date` | 日期 | 实际完成日期 |
| `progress` | 数字 | 进度百分比 0–100 |
| `priority` | 数字 | 优先级 **1–5，1 最高**：1🔴 最高、2🟠 高、3🟡 中、4🔵 低、5⚪ 最低 |
| `area` | 文本 | 所属领域，**单值**（用于分组与筛选）；历史笔记里写成数组时取第一个 |
| `objective` | 文本 | 项目目标 |
| `context` | 文本 | 背景 / 上下文 |
| `remark` | 多行文本 | 备注：状态变更、决策、卡点等零碎记录 |
| `project-leader` | 文本 | 负责人 |
| `project-members` | 列表 | 成员 |
| `long-term` | 布尔 | 长期项目：**不上甘特图、豁免所有日期筛选**，只在左侧面板出现（置顶） |
| `main-project` | 布尔 | 主项目标记：同一文件夹有多个项目笔记时，以主项目为分组代表；无标记且多于一个会出「多项目」提醒 |
| `project-id` | 文本 | 项目编号 |
| `color` | 颜色 | 甘特条自定义颜色（CSS 颜色值）；格式非法时忽略并提示 |

## 状态值

七种状态，中英文别名等价（可在设置中扩展），默认顺序即新建下拉的顺序：

| 值 | 中文别名 | 含义 |
| --- | --- | --- |
| `inbox` | 未开始/待启动 | 还没启动 |
| `draft` | 起草/构思中 | 构思阶段 |
| `active` | 执行中 | 进行中 |
| `on-hold` | 暂停 | 临时挂起 |
| `completed` | 完成 | 已完成 |
| `cancelled` | 取消 | 已取消（**仍出现在甘特图上**，可用状态筛选隐藏） |
| `archived` | 归档 | 归档 |

## 日期缺失时的兜底

起止日期不全时按「设置 → 全局参数」的兜底策略处理，默认**按天数推导**（7 天）：

- 有 `due_date` 缺 `start_date` → 开始 = 截止 − 7 天；
- 有 `start_date` 缺 `due_date`（且无 `end_date`）→ 截止 = 开始 + 7 天；
- 两个都没有 → 不上图，界面顶部会写明原因与数量。

## 甘特条颜色

四类配色（设置中可改）：**执行中**蓝、**完成**绿、**重要**（优先级 1 / 2，外圈描边）红、**其他状态**灰。笔记里 `color` 字段可对单个项目覆盖。

## 快速项目标记

路径中名为「快速项目」的目录段（设置可改）有特殊分组含义：分组划分止于该段，标题用「 > 」连接——通过「新建项目」快速创建的项目默认落在 `快速项目/` 目录下，自动归为一组。
