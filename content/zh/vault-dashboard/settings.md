设置入口：Obsidian 设置 → 第三方插件 → **Vault Dashboard**。所有改动即时生效并保存。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 界面语言 | 跟随 Obsidian | 可选：跟随 Obsidian / 中文 / 英文 |
| 排版密度 | 宽松 | 宽松 / 紧凑，控制组件内边距与字号 |
| 启动时自动打开 | 开 | 启动 Obsidian 时自动打开工作台 |
| 自动打开方式 | 新标签页 | 新标签页 / 替换当前标签页 |
| 日志目录 | 空 | [今日任务](components/#今日任务)扫描的日记目录，如 `500 Journal`；留空则该组件不显示内容 |
| 日期格式 | `YYYY-MM-DD` | 解析日记文件名用的 [moment 格式](https://momentjs.com/docs/#/displaying/format/)，需与文件名一致（如 `YYYY-MM-DD` 对应 `2026-10-01.md`） |
| 排除目录 | 空 | 逗号分隔的目录列表，不计入统计与历史。**修改后历史会整体重建**（口径必须一致，否则趋势图会出现假跳变） |
| 空/短笔记阈值 | 10 | 字数低于该值的笔记算「短笔记」 |
| 最近天数 | 7 | 「最近完成」任务与最近列表的回看窗口（天） |
| 显示估算历史 | 开 | 是否在趋势图中显示按文件创建时间估算的历史段 |
| 允许执行自定义脚本 | **关** | 开启后才能添加[自定义脚本组件](components/#自定义脚本组件) |
| 脚本目录 | （只读展示） | 脚本存放位置：`.obsidian/plugins/vault-dashboard/data/`；「新建脚本」生成入门模板 |
| 清空历史 | — | 手动清空全部历史快照（布局与设置保留） |

## 数据存储

- **`data.json`**（`.obsidian/plugins/vault-dashboard/`）：设置、工作台布局与历史快照都存在这一个文件里；
- **`data/` 子目录**：自定义脚本。

两者都在插件目录内：不随笔记同步（除非你同步整个 `.obsidian`），卸载插件时会一并删除——换机或重装前请自行备份，详见[常见问题](faq/)。
