## 常见问题

**任务存在哪里？**

就是你笔记里的 Markdown 复选框——没有数据库、没有导出步骤。仪表盘上做的每个操作（勾选、改期、拖拽换列）最终都写回那一行任务文本；卸载插件后任务一个不少。

**为什么有的任务不进甘特图？**

完全没有起止日期的任务放不进时间轴，会被排除；侧栏头部会写明排除了几条，不会有任务无声消失。只有一个日期的任务会正常画条，缺失的另一端自动推断并以橙色虚线描边。

**`- [/]` 算什么状态？**

不是独立状态。有过去的开始日期、或带 `#doing` / `#active` / `#next` 标签的任务就算进行中——`/` 标记本身不参与判定。

**扫描全库可以吗？**

可以（扫描目录留空即可），但大库会明显变慢，建议指定目录并配合排除目录。

**手动安装后插件没出现？**

文件夹名必须与插件 id 一致：`task-matrix-dashboard`。Obsidian 只认这个目录名。

## 数据与隐私

Task Matrix 完全在你的 vault 内运行：

- 无网络请求、无遥测、无账号登录；
- 只读写你 vault 里已存在的 Markdown 文件，且只动你操作的那一行任务；
- 设置经 Obsidian 插件数据 API 存在你 vault 的 `.obsidian` 目录里。

## 已知限制

- 拖拽改状态仅桌面可用（移动端用卡片快捷按钮）；
- Mermaid 不支持逐条任务单独配色（Mermaid 自身限制）；
- 新建任务依赖下拉只列出**未完成**且带 ID 的任务。
