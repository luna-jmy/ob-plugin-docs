设置入口：Obsidian 设置 → 第三方插件 → **Task Matrix**。设置按视图的同一套结构分组。

## 界面

| 设置 | 说明 |
| --- | --- |
| 界面语言 | 自动（跟随 Obsidian）/ 中文 / English |

## 扫描

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 扫描目录 | `500 Journal, 100 Projects` | 逗号分隔（全角逗号 / 分号也认），支持多级路径如 `300 Resources/360 WorkMemos`，路径匹配不分大小写；**清空则扫全库**（大库会慢） |
| 排除目录 | — | 这些目录里的任务不进任何视图与计数 |

## 任务标记

- **完成标记 / 取消标记**：方括号里写什么算完成 / 取消（默认 `x` / `-`）；
- **忽略标记**：哪些方括号内容根本不算任务；
- **记录完成日期**：完成任务时自动补 `✅ YYYY-MM-DD`。

## 显示

- 默认视图、打开位置；
- **紧急窗口**：多少天内到期算紧急（1–7 天）；
- 截止日期范围、已完成任务范围、**隐藏远期才开始的任务**：一次铺开多少内容；
- 显示没有截止日期的已完成任务。

## 新建任务

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 目标笔记路径 | 今天的日记 | 新任务写进哪篇笔记；支持 `{{title}}`、`{{date}}`、`{{time}}`、`{{date:格式}}` 占位符；笔记不存在会自动创建；**留空 = 当前打开的笔记** |
| 目标标题 | 空 | 插到该标题之下；留空追加到笔记末尾 |
| 日记模板 | — | 目标笔记不存在时复制这篇模板（`{{title}}` 是文件名；`<% … %>` 命令留给 Templater 展开） |

## 列表视图

- **按目录分组**（默认关）：关 = 每篇笔记一个容器（容器头的 `+` 直接往该笔记加任务）；开 = 容器挂在可折叠的目录小节下；
- 小节名用**扫描目录的完整路径**：加进扫描清单的子目录自成小节，其下内容都归它；没配扫描目录时用每篇笔记自己的目录路径。

## GTD 与四象限

页签分两半——**什么决定列**与**拖拽写入什么**。只有标签词表与紧急窗口可调；规则本身写在设置页上而不是做成开关——会破坏分类或拖拽的开关不是参数。

**分类**

- **等待标签**与**进行中标签**：决定任务落哪列（第一个条目同时是拖过去时写入的标签——一份词表两用，拖过的任务不会弹回原列）；
- **紧急天数**：多近算紧急，决定四象限的紧急侧；
- 规则顺序就写在页面上：依赖或等待标签 → 等待；进行中标签 → 进行中；已逾期 → 逾期；开始日期已过 → 进行中；开始日期在未来 → 待开始（并入收件箱）；否则收件箱。

**拖拽**

- **启用拖拽**：总开关，关掉后容器不再接受拖放、卡片不可拖动；卡片快捷按钮与甘特右键菜单照常可用。关闭时下方各项一并禁用；
- **拖拽写入内容**是固定的、白纸黑字写在页面上（详见[任务语法](syntax/#拖拽写入什么)）；
- **各象限写入什么**：每个象限一个「重要性」下拉，选项限制在该象限自己那一侧——Q1/Q2 高及以上、Q3/Q4 中及以下或不写。

## 日历视图

每周第一天、月 / 周视图里的周末、列表视图是否整月、进行中的任务是否铺满其日期区间。

## 甘特视图

- **条上天数**：不显示 / 日历天（含首尾）/ 工作日（与阴影列、导出共用同一套日历）；
- **条色**：对应 Mermaid 的 `active` / `done` / `crit` / 其他各一色，填 CSS 颜色或点色板；
- **任务列宽**：甘特左侧任务列的宽度（也可在甘特里直接拖）；
- **图表标题与标记**：导出代码的 `title` 行，以及「写入笔记」替换的上下一对标记（默认 `%% task-matrix:start %%` … `%% task-matrix:end %%`）。今天线、周末标记与两个日期栏在预览 Tab 上，边看图边调。

## 法定节假日排期

按年维护——假期就是按年公布的：添加年份后填**节假日**（`10-01~10-07`，`~` 或 `至`，区间可跨年）与**调休工作日**。导出时区间展开为单个日期（Mermaid 的要求）。甘特跨到哪年自动应用哪年；预览 Tab 上的日期栏只做临时增补。
