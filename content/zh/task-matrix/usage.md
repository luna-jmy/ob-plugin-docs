## 界面布局

视图自上而下三行：

1. **工具栏**——新建任务、刷新、四个面板模式按钮（列表 / GTD / 四象限 / 日历）、**甘特模式**开关、**收起筛选**（筛选栏默认展开）；还有一个全部展开 / 收起按钮，按钮文字会预告下一步动作（所有容器都展开时才显示「全部收起」）。点开甘特模式后，面板按钮换甘特自己的控件（时间刻度与分组），按钮变为「退出甘特模式」，退出后回到你之前所在的面板模式；
2. **筛选栏**——搜索、状态片、起止日期区间、排序、实时的「命中 / 总数」计数与一键清空；
3. **主区**——等宽容器装任务卡，任何窗口宽度下网格都保持对称。

## 四种面板视图

| 视图 | 布局 | 适合 |
|------|--------|----------|
| **📋 列表** | 每篇笔记一个容器；开分组后容器挂在可折叠的目录小节下 | 浏览全部 |
| **📥 GTD** | 四个容器：收件箱、进行中、等待、完成 | 顺着流程推进 |
| **🔳 四象限** | 四个容器：Q1–Q4 | 决定什么重要 |
| **🗓 日历** | 月 / 周 / 列表 | 按日期规划 |

日历视图里悬停条目即时显示任务与其所在笔记的提示框，无需等页面预览延迟。甘特图是独立「模式」而非第五个面板，详见[甘特图指南](gantt/)。

## 任务卡

每张卡显示渲染后的描述、状态徽章，以及优先级、日期、任务 ID、依赖的小片。可用操作：

- ✓ 完成 / ↺ 重开（开启「记录完成日期」时补写 `✅ YYYY-MM-DD`）；
- ▶ 开始（写入 `🛫` 与 `#doing`）；
- ✕ 取消；
- ✎ 编辑——描述（双行文本框，标签直接写在里面，下方有可点的标签片）、优先级、日期、ID、依赖；
- 🗑 删除；
- 四象限与 GTD 视图里的 1–4 与 收 / 进 / 等 快捷移动按钮；
- 点卡片本体打开它所在的笔记。

**依赖未完成**的任务（`⛔` 指向的任务还没完成）左边框标红，一眼看出谁被卡住。

**标签就写在描述里**，位置与笔记中一模一样——没有单独的标签栏，查找只有一处。描述框下方一排标签片：点一下写入描述，再点一下移除。候选来自你 vault 里实际用过的标签（按使用频次排序，外加本任务自己的），所以很少需要手打，`#work` / `#work-items` 这类变体也不会越积越多。保存时只在该标签集合确实变化的情况下，把它抽出并重写到行尾；行内其余部分（包括行内字段位置）原样保留，什么都没改就不重写这一行。

**列表视图用同样的任务卡**——完成 / 开始 / 取消 / 编辑 / 删除都可用——只有两点不同：卡片不再重复显示笔记路径（容器就是笔记；开目录分组后卡片只显示笔记名），以及卡片不能拖到别的容器（列表容器是「地方」不是「状态」）。

## 任务怎么分类

- **GTD** 由标签（`#waiting`、`#doing`、`#blocked`）、开始日期与依赖推导；逾期但从未开始的任务回落到收件箱，而不是单占一列；
- **四象限**：高优先级及以上算「重要」；在「紧急窗口」（1–7 天，可设）内到期的算「紧急」；
- **排期**只以纯 Markdown 写入：`📅` 截止、`🛫` 开始、`⏳` 计划、`✅` 完成、`➕` 创建、`🆔` 任务 ID、`⛔` 依赖，外加你自己的 `#标签`。完整语法见[任务语法](syntax/)。

## 筛选

- **搜索**：匹配描述、文件路径、任务 ID 与依赖 ID；
- **状态片**：打开 / 待开始 / 逾期 / 已完成 / 已取消，附「只看进行中」「隐藏已取消」「全部状态」三档预设；
- **标记片**：按方括号里实际内容筛（`[ ]`、`[x]`、`[-]`、`/` 或你自定义的标记）；候选来自你的 vault，没用到过的标记不会出现成死片；
- **起止日期**：预设（今天 / 本周 / 本月 / 今年 / 自定义）加明确的区间；改动任一端自动切为自定义区间；
- **排序**：截止 ↑ / ↓、开始 ↑、优先级、文件名；
- 计数实时显示当前筛选命中的任务数；**清空筛选**回到什么都不筛的基线。

## 拖拽

- 把卡片拖到 **GTD 容器**改状态，拖到**四象限容器**改象限；
- 松手写入的内容与快捷按钮完全一致（详见[任务语法](syntax/#拖拽写入什么)）；
- 拖拽仅桌面可用；移动端请用卡片上的快捷移动按钮。

## 移动端

工具栏与筛选栏自动换行不溢出；窄屏容器退化为单列；卡片所有操作点按可达。
