设置入口：Obsidian 设置 → 第三方插件 → **Quick Journal**。

## 期间页签（日 / 周 / 月 / 年）

四个页签结构相同，各自独立配置：

| 设置 | 默认（以「日」为例） | 说明 |
| --- | --- | --- |
| 目录 | `500 Journal/540 Daily` | 该期间日志存放目录（周 `530 Weekly` / 月 `520 Monthly` / 年 `510 Annual`） |
| 文件名格式 | `YYYY-MM-DD` | moment 格式（周 `YYYY-[W]ww`、月 `YYYY-MM`、年 `YYYY`） |
| 模板笔记 | 空 | 「从模板识别」读取的模板路径 |
| 标题区列表 | 每日五个（见[使用指南](usage/#六种标题区)） | 每区：标题、类型、字段（键 / 展示名 / 单位）、行模板、系列标记与系列名（对比数据）、是否带时间戳、是否上速记面板 |

标题区字段与列表类型随「类型」变化：打卡 / 数据 / 文本区配内联字段，列表区配行模板，段落区无需字段；对比数据区在字段（维度）之外再配两个**系列**（emoji 标记 + 系列名），笔记里写入的键 = 基础键 + 系列标记。

## 全局设置

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 界面语言 | 跟随 Obsidian | 中 / 英 |
| 汇总打开位置 | 标签页 | 日志汇总开在标签页或右侧边栏 |
| 面板打开位置 | 标签页 | 速记面板同上 |
| 显示已完成任务 | 关 | 速记面板与汇总的持久开关 |
| 统计含非日记任务 | 关 | 任务图 / 热力图是否计入日志目录之外的任务 |
| 任务标记：打开 / 完成 / 取消 / 非任务 | `[ ]` / `x` / `-` / … | 速记面板与汇总识别任务行用的方括号标记 |
| 未完成标记 | 空格 + `>` | 「未完成任务滚动」搬运时识别未完成的标记 |
| 自动时间戳 | 关 | 速记面板新记录是否自动加时间戳 |
| 趋势字段 | 空 | 数据趋势组件默认选中的字段 |
| 汇总查询列表 | 空 | 汇总布局里手工录入的查询块（标题 + 代码），编辑模式维护 |
| 恢复默认设置 | — | 一键重置**全部插件配置**（不动笔记内容） |

## 汇总布局

编辑模式（汇总视图工具栏齿轮）里维护：组件的拖拽排序、删除、添加；布局与查询列表存在插件数据里，随配置一起备份 / 重置。
