## 快速录入

左侧 ribbon 图标 → 命令「打开快速录入」打开表单：**选标题区 → 填内容 → 提交**，写进当前期间日志的对应标题之下。每个标题区另有一条独立命令（如「快速录入： 周 · 周末回顾与总结」），可绑快捷键或加进移动端工具栏，一步直达。

- 再次打开时，字段会用**当前值预填**——补录、改录都方便；
- 覆盖已有值前会**弹窗确认**（数据、文本、段落区）；
- 段落区重开即编辑：表单里带出已有内容，改完覆盖。

## 六种标题区

标题区以日志里的**标题（heading）**为单元，类型决定录入方式：

| 类型 | 录入方式 | 例子 |
| --- | --- | --- |
| **打卡** | 每个内联字段一组 ✔️/❌ 开关；不选不写 | 每日打卡：吃药、冥想…… |
| **数据** | 内联字段填数值（带单位） | 体重、运动分钟、支出…… |
| **文本** | 每个内联字段一句话 | 今日小结的四个问题 |
| **列表** | 逐项追加一行；行模板可配 | `- [ ] {{value}}` 记任务 |
| **段落** | 一天一条的整段自由文字，可长 | 周末回顾与总结 |
| **对比数据** | 每个维度两列数值成对录入，汇总里画雷达图 | 生命之轮：年初目标 vs 年底复盘 |

默认每日配置即按此搭建：`### 每日打卡`（4 项）、`### 数据记录`（5 项）、`## ✍️ 今日小结与回顾`（4 问）、`## 👀 GTD任务看板`（列表，行模板 `- [ ] {{value}}`）、`## 💡 灵感与思考`（列表 + 时间戳）。周 / 月各预置一个复盘文本区，年不预置。

### 对比数据与系列标记

对比数据区把**同一维度的两组数值**记在一个标题区下，典型用法是年度「生命之轮」：每个维度年初定目标、年底做复盘。配置只建**一个标题区**：

- 字段 = 维度（基础键，如 `PersonalGrowth`、`HealthFitness`）；
- 区段配两个**系列**，各带一个**系列标记**（emoji，默认 🎯 / 🏆）与**系列名**（显示用，如「年初目标」「年底复盘」）；
- 笔记里实际写入的字段键 = **基础键 + 系列标记**：

```markdown
### 生命之轮
- [PersonalGrowth🎯:: 7]
- [HealthFitness🎯:: 6]
- ……
- [PersonalGrowth🏆:: 8]
- [HealthFitness🏆:: 7]
```

配对按「去掉系列标记后基础键相同」自动完成——维度增删只改一处，两列永不错位。快速录入弹窗按「维度 × 两个系列」出两列数值输入；日志汇总的[对比雷达图](summary/#组件)会把两个系列画在同一张雷达图上（周 / 月 / 年视图分别读对应期间笔记里的对比区段，季度视图读年度）。

## 速记面板

命令「打开速记面板」——类 Thino 的内容流：

- **卡片式录入区**置顶：选标题区直接发，列表区逐条追加、段落区一天一条（重发即编辑）；
- **标题筛选**同时控制输入区与展示区：选「灵感与思考」就只看灵感；
- **任务**：点行首状态符号即可完成 / 取消（标记可配）；每条记录带**编辑 / 删除 / 跳转原文 / 与任务列表互转**；
- **搜索**、可选**自动时间戳**；日志文件变更自动刷新；
- 顶部可收起（手机端友好）；「显示已完成任务」为持久设置；
- **未完成任务滚动按钮**：把上一期日志里未完成的任务搬到今天（未完成标记可配，默认空格 + `>`）。

## 多期间日志

设置按 **日 / 周 / 月 / 年** 分页签，各自配置目录、文件名格式与快速录入标题区：

| 期间 | 默认目录 | 文件名格式 |
| --- | --- | --- |
| 日 | `500 Journal/540 Daily` | `YYYY-MM-DD` |
| 周 | `500 Journal/530 Weekly` | `YYYY-[W]ww`（ISO 周） |
| 月 | `500 Journal/520 Monthly` | `YYYY-MM` |
| 年 | `500 Journal/510 Annual` | `YYYY` |

周 / 月 / 年的**复盘**就是对应期间下的文本标题区（默认按现行模板字段预置），用该区的快速录入命令填写；汇总视图里的快速录入条覆盖全部期间。

## 从模板识别

已有自己的日志模板？设置里填模板笔记路径点一下，插件按模板的**标题与内联字段**自动重建对应期间的标题区配置（四种期间的模板都能识别）：

- 展示名默认取字段键去掉 emoji，可手改；
- 字段键全部呈「基础键 + 同两个 emoji 后缀」时自动识别为**对比数据**区（系列标记即该两个 emoji，系列名默认同标记，可手改）；
- 目录支持递归（模板在子目录里也能找到）；
- 文件名格式跟着期间走，可自定义。

## 自动建笔记

提交时目标日志不存在？插件按标题区配置**自动创建**：frontmatter + 标题 + 空值字段行的骨架（不带查询块与按钮），然后照常写入。录入永不被「还没建今天的笔记」打断。
