命令「打开日志汇总」打开仪表盘视图：所有期间的数据汇成一块可拼装的看板。工具栏齿轮进入**编辑模式**——拖拽排序、删除、添加组件；汇总布局的查询列表也在编辑模式里维护。

{{< screenshot src="images/quick-journal/summary-view.png" caption="日志汇总视图" >}}

## 组件

| 组件 | 内容 |
| --- | --- |
| **快速录入条** | 汇总视图顶部的快捷录入条，只显示当前查看期间（周 / 月 / 季 / 年）日志的标题区按钮；该期间无标题区时整条隐藏 |
| **日志录入** | 日志（daily）全部标题区的快捷按钮卡片，所有期间视图可见，可在编辑模式里排序 / 隐藏 |
| **任务图** | 任务完成情况的指标 + 柱状图；周 / 月期间按天、季 / 年期间按月聚合 |
| **打卡汇总** | 每个打卡字段的完成比例条：完成 / 未完成 / 未记录三段 |
| **数据趋势** | 单选一个数据字段画折线（带坐标轴与最新 / 最大 / 最小值） |
| **对比雷达图** | 对比数据标题区的两个系列画在同一张雷达图（如年度目标 vs 年底复盘）；周 / 月 / 季 / 年视图读对应期间笔记里的对比区段；刻度上限取 10 与实际最大值的较大者 |
| **月历** | 年 / 月切换 + 周号列；点日期或周号打开对应日志 / 复盘笔记；任务完成的日期带徽标，有记录的日期带圆点 |
| **热力图** | 任务完成与内容记录两张热力图，形态随期间自适应：周 = 7 个大格、月 = 日历格、年 = 小格 |
| **最近速记** | 内容流里最近 8 条 |
| **查询块** | 渲染你手动添加的 `dataview` / `dataviewjs` 查询（见下） |

图表全部原生自绘，无外部依赖；汇总里「显示已完成任务」「统计含非日记任务」等开关在设置里配。

## 查询块

查询块组件渲染你在**编辑模式里手动添加**的查询——没有预设，也不自动识别日志笔记里已有的代码块；查询（标题 + 类型 + 语句）存在插件配置里，随时增删改：

- 类型仅两种：`dataview` 与 `dataviewjs`，渲染委托 Dataview 插件（未安装则显示提示）；
- 每条查询可配一个**标题**，展示在结果上方；
- 常见用法：在汇总里放一张最近日志的表格、一个跨目录的任务清单。

````markdown
```dataview
TABLE 完成, 体重 FROM "500 Journal/540 Daily" LIMIT 7
```
````

## 与速记面板的分工

- **速记面板**面向「现在记一下」：输入区置顶、内容流即写即见；
- **日志汇总**面向「回头看清况」：图表、月历、趋势与查询块。

两者共享同一份日志数据，开在哪（标签页 / 右侧边栏）各自记住。
